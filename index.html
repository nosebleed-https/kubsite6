Как пользоваться калькулятором

  1. Введите количество товара цифрами.
  2. Выберите товар.
  3. Для тетради выберите количество листов, для папки — отметьте «С кнопкой-застёжкой».
  4. Итоговая стоимость обновляется сразу, кнопок нажимать не нужно.
